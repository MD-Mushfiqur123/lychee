### Health & Metadata

| Method | Path | Description |
|:---|:---|:---|
| `GET` | `http://localhost:11434/` | Health check / Web Dashboard (SPA) |
| `GET` | `http://localhost:11434/api/version` | Server version |

### Model Management

| Method | Path | Description |
|:---|:---|:---|
| `GET` | `http://localhost:11434/api/tags` | List all models |
| `GET` | `http://localhost:11434/api/ps` | List running models |
| `POST` | `http://localhost:11434/api/show` | Show model details |
| `POST` | `http://localhost:11434/api/pull` | Pull model from HuggingFace |
| `POST` | `http://localhost:11434/api/push` | Push model |
| `POST` | `http://localhost:11434/api/create` | Create model |
| `POST` | `http://localhost:11434/api/copy` | Copy model |
| `DELETE` | `http://localhost:11434/api/delete` | Delete model |

### Inference

| Method | Path | Description |
|:---|:---|:---|
| `POST` | `http://localhost:11434/api/generate` | Text generation |
| `POST` | `http://localhost:11434/api/chat` | Chat completions |
| `POST` | `http://localhost:11434/api/embed` | Get embeddings |

### Orchestration (Lychee-extended)

| Method | Path | Description |
|:---|:---|:---|

| `POST` | `http://localhost:11434/api/conversations` | Persistent conversation memory |
