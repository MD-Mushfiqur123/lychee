# Lychee Examples

Example files demonstrating Lychee's Modelfile format and configuration.

## Files

- **Modelfile.example** — A complete Modelfile with commented directives (`FROM`, `SYSTEM`, `PARAMETER`, `TEMPLATE`) showing how to define and customize a model for Lychee.
- **.lycheeignore** — Standard ignore patterns for the Lychee models directory (at the project root), excluding large model binaries (`.gguf`, `.safetensors`, `.bin`, `.pt`, `.pth`) while keeping Modelfiles.
